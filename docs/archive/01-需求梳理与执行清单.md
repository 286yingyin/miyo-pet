## 一、需求确认（我的理解）

老师要的是一个**常驻桌面的桌宠程序**，形象是《蔚蓝档案》的樱井美代。核心不是"好看的摆件"，而是**把 WorkBuddy 的后台工作状态，用美代的表情和动作实时表达出来**。

拆成 5 条可验收需求：

| 编号 | 需求 | 我的理解 | 验收标准 |
|---|---|---|---|
| R1 | 形象与素材 | 用官方立绘差分还原美代 | 差分就位、透明底、可切换 |
| R2 | 状态驱动表情/动作 | 不同工作状态 → 不同表情与动作 | 状态变更后 ≤300ms 完成切换 |
| R3 | 两类动态提示 | ①「正在处理 x 个任务中」②「有 x 个任务需要确认」 | 数量与文案正确；x=0 时不显示 |
| R4 | 状态数据可动态更新 | 外部能实时推/拉状态，且不刷新页面 | 注入后画面即时更新 |
| R5 | 桌面常驻形态 | 透明、置顶、可拖动 | P1 由 Electron 承载 |

> R5 不在本轮 demo 范围 —— demo 先在浏览器里把**交互与视觉**确认清楚，再套壳。

## 二、素材调研结论（实测，非推测）

按老师给的 kivo.wiki 站点做完整勘察，结论如下。

### 2.1 数据通道
- 站点是 Vue SPA，数据来自 `https://api.kivo.wiki/api/v1`
- 角色接口：`GET /api/v1/data/students/554` —— **无需登录**，带 Referer 即可
- 静态素材服务器：`https://static.kivo.wiki` —— **无防盗链，可直接下载**

### 2.2 已取到的素材

| 素材 | 数量 / 规格 | 用途 |
|---|---|---|
| **初始立绘差分** | **40 张**，948×948 PNG，**含透明通道** | R1 / R2 主素材 |
| 官方语音 | **91 条** OGG（大厅 23 / 战斗 32 / 活动 18 / 养成 10 / 咖啡厅 5 / 编队 3） | 可选：点击回应 |
| Spine 立绘模型 | `CH0317_spr_HD`（.skel + .atlas + .png） | P1 可选：真骨骼动画 |
| Spine 记忆大厅 | `CH0317_home`（.skel + .atlas + 3×.png） | P1 可选 |
| 3D 模型 | `CH0317_Body.glb`、`CH0317_Halo.obj` | 备选 |
| 头像 / 图标 | Student_Portrait、Weapon_Icon、skill_icon ×5 | 托盘图标 |

差分素材已下载到 `prototype/v1/assets/spr/`（40 张，48 MB）。

### 2.3 一个必须请老师拍板的点：走哪条技术路线

老师说的是「Live2D」，但《蔚蓝档案》实际用的是 **Spine 骨骼动画**（不是 Live2D）。我实测后发现两条路都能走：

| 方案 | 效果 | 素材 | 依赖 | 我的评估 |
|---|---|---|---|---|
| **A. 立绘差分 + 程序动效** | 呼吸、摇曳、眨眼、表情切换 | 40 张 PNG（已取得） | **零依赖** | 立即可跑，风险为零 |
| **B. Spine 骨骼动画** | 官方原版骨骼动效（真·可动） | .skel / .atlas / .png（已定位） | 需 `spine-webgl`（~1 MB）+ Spine runtime 许可 | 效果最好，但引入依赖与授权问题 |

**本轮 demo 走 A**（贴合老师「立绘差分」的原话，且零依赖）；**B 作为 P1 升级选项**，等老师定。

## 三、状态机设计

### 3.1 三态 + 优先级

```
pending > 0      →  待确认态   （最高优先级）
processing > 0   →  处理中态
否则             →  待机态
```

**优先级理由**：待确认是「卡住等老师」的状态，必须先被看到。

### 3.2 叠加修饰

- **夜间**（23:00–06:00）→ 冷色调 + 台词变化
- **数量变化** → 一次轻微的「点头」反馈

### 3.3 表情映射（**可配置**）

| 状态 | 差分 | 动作 | 台词（美代语气） |
|---|---|---|---|
| 待机 | spr_00 | 呼吸 | 「……现在没有待办。要不要，一起读点什么？」 |
| 处理中 | spr_09 | 打字机节奏的轻晃 | 「正在处理 3 个任务……我先盯着，老师。」 |
| 待确认 | spr_21 | 抬头 + 气泡闪烁 | 「有 2 个任务需要确认……这个，您看过了吗？」 |
| 处理中 + 待确认 | spr_21 | 同上 | 「处理中 3 件，另有 2 件等您确认……」 |

> 官方差分没有公开的「编号 → 表情」对照表，以上是我**逐张目视判定**的。demo 里做了**可视化选图面板**，老师可以直接指定每个状态用哪张，改完即生效。

## 五、待老师确认的 4 个问题

1. **技术路线**：demo 用 A（立绘差分 + 程序动效），P1 是否升级到 B（Spine 骨骼）？

4. **素材范围**：40 张差分全部启用，还是只挑几张？
