## 二、v2 的 8 个状态

| 状态 | 触发条件 | 表情 | 标签 | 台词 |
|---|---|---|---|---|
| `idle` | 无任务、未空闲 | `Idle_01` | 平静1级 | ……现在没有待办。要不要，一起读点什么？ |
| `processing` | `processing > 0` | `36` | 认真1级 | 正在处理 N 个任务……我先盯着，老师。 |
| `pending` | `pending > 0`（最高优先） | `24` | 惊讶2级 | 有 N 个任务需要确认……这个，您看过了吗？ |
| `done` | 任务数归零后 8 秒内 | `13` | 开心3级 | ……都做完了。 |
| `error` | 手动/接口置入 | `33` | 难过3级 | ……好像出了点问题。 |
| `idle_5` | 空闲 5–15 分钟 | `20` | 生气1级 | ……老师，还在吗。 |
| `idle_15` | 空闲 15–30 分钟 | `18` | 生气2级 | （抱着稿子鼓着脸）……我又不是摆设。 |
| `idle_30` | 空闲 30 分钟以上 | `16` | 生气3级 | （别过脸去）……您忙您的，不用管我。 |

**优先级**：`pending > processing > done(限时) > 空闲生气 > idle`

### 空闲生气机制

- 真实阈值 **5 / 15 / 30 分钟**，三级递进
- 演示时可切换 **1× / 60× / 300×** 倍速，或点「直接跳到 30 分」
- **老师任何操作**（点击、任务变化）→ 立刻回到当前工作状态对应的表情

## 三、做过的两处逻辑修正

| 问题 | 现象 | 修正 |
|---|---|---|
| 空闲倍速默认 60× | 页面加载 15 秒就显示「空闲15分」 | 默认改 **1×**（真实时间），加速交给按钮 |
| 完成态卡死 | 任务归零后 `done` 永久为真，不进入空闲生气 | 加 **`doneUntil` 8 秒时效**，过期交给空闲计时 |

## 三·B、本轮追加的两项改动（v1 / v2 同步）

### 1. 表情映射支持「一个状态 → 多个表情」

**结构变更**：`MAP[mode].spr`（单值）→ **`MAP[mode].sprs`（数组）**

```js
// 之前
{ processing: { spr: '36', ... } }
// 现在
{ processing: { sprs: ['36', '09'], ... } }
```

**行为**：
- 一个状态关联多个表情时，**每 7 秒自动轮播**一个（带 170ms 淡入淡出）
- 只有一个表情时**不轮播**
- 切换用 `setBaseSrc()` 做淡入，避免突兀跳变

**交互**（控制台）：
- 每个状态一行，已选表情显示为 chips，点 **×** 移除（至少保留一个）
- 右侧下拉「＋添加」可追加
- **点画廊任意图 → 追加到当前状态**
- 画廊里：实心绿 = 正在显示；金边 = 属于某状态但不是当前帧

**接口**：
```js
MiyoPet.getMapping();                       // { idle:['Idle_01','01'], processing:['36'], ... }
MiyoPet.setMapping('processing', ['36','09']);  // 传数组；传单值也兼容
MiyoPet.getSpr();                           // 当前实际显示的那一张
```

### 2. 降低摇晃幅度、放慢周期

| 动作 | 位移 | 旋转 | 周期 |
|---|---|---|---|
| 呼吸（待机） | 6px → **3px** | — | 4.4s → **6.0s** |
| 处理中 | 5px → **2.2px** | 0.5° → **0.22°** | 1.9s → **2.8s** |
| 待确认 | 12px → **6px** | — | 2.4s → **3.2s** |
| 生气1/2级 | 4px → **2px** | 0.8° → **0.35°** | 2.6/1.9s → **3.6/3.0s** |
| 生气3级 | 5px → **2.2px** | 1.4° → **0.6°** | 1.5s → **2.6s** |

v1 同步收敛（实测最大位移 6px，原先 12px）。
