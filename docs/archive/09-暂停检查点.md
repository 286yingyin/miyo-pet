## 6. 环境约束（每次都会踩，务必记住）

| 现象 | 处理 |
|---|---|
| `node` 目录版本会变（本次 `22.22.2-3` → `22.22.2-6`） | 先 `ls ~/.workbuddy/binaries/node/versions/` 再定路径，**别硬编码** |
| Bash 默认 PATH 缺 `dirname`/`ls` 等 | 每条命令开头显式 export PATH（含 PortableGit bin） |
| ~~Node 无法 spawn 子进程（EBUSY）~~ | **该结论已被推翻**（见下方「勘误」）：Node 可正常 spawn；当时是 PATH 里缺 powershell.exe 导致的误判 |
| **Git Bash 会把 `/N` `/Q` 这类开关当路径转换** | 从 Bash 调 Windows 原生工具时必须加 `MSYS_NO_PATHCONV=1`；或改由 Node `spawnSync` 调用 |
| `fs.cpSync` 静默被杀（exit 127） | 用 `readdirSync` + `mkdirSync` + `copyFileSync` 手写递归 |
| `tasklist //FI "IMAGENAME eq x.exe"` 恒返回空 | 改用 `tasklist \| grep -i x` |
| 截屏被安全策略拦（Add-Type / Reflection） | 视觉确认只能请老师看 |
| Bash 调 `cmd` / `powershell.exe` 被拦 | 用 PowerShell 工具，或用 Bash 原生命令 |
| 命令结束会回收子进程 | GUI/长驻程序请老师自己启动 |
| **同文件多处改动必须逐条串行 Edit** | 并行会导致「丢更新」（本次已踩过） |
| `python` 不在 PATH | 用绝对路径 `...\python\versions\3.13.12\python.exe` |

## 7. 不可变的设计约定（改动前先确认）

- v1 与 v2 的**外部接口必须完全一致**：`setState / getState / getMode / getSpr / getMapping / setMapping / react / liveLine / reaction / isHosted / setApprovalVisible`
- 原型是**单文件零依赖 HTML**；交付前必过 `node scripts/check.js` + `node scripts/test-status.js`
- **只有 `ok===true` 的快照才允许产生 `justDone`**；读失败一律沿用上次已知值，绝不归零
- 表情映射结构 `MAP[mode] = { sprs:[...], blink, blinkOn }`；多张时 7 秒轮播；反应进行中不轮播
- 动作位移上限 **≤ 4px**（自检里有回归断言）
- 统计范围默认 `current`；`all` 时 7 天前的未完任务计入 `stale` 不进数字
