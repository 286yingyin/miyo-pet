# 完整需求池与版本路线

状态：需求汇总已建立，后续版本顺序待随每版评审调整。创建：2026-10-15。代码基线：`9ff3645` / 应用 `0.3.23`。

## 产品方向

把美代桌宠逐步扩展为可换角色、可感知常用 Agent 工作、适合长期常驻的桌面伙伴。保留现有台本、语音、提醒和低依赖特点；系统监控、角色表现、Agent 接入分开建设。

范围来自项目调研和用户讨论。下列需求全部保留在需求池；“已收录”不等于“已实现”，后续候选也不等于发布承诺。每项 ID 跨版本不变。

## 建议迭代

| 迭代 | 交付主题 | 出口条件 |
| --- | --- | --- |
| v0.4.0，第一版 | Windows 稳定、macOS 基础可用、Codex **桌面端**、角色独立配置 | [首版需求](../iterations/v0.4.0/requirements.md)逐项验收；桌面事件入口与 Mac 实机验证是必要条件 |
| v0.5.0，候选 | 长期常驻体验：安静 / 全屏、穿透、多屏 / 记位 / 贴边 | 不打断全屏应用；可恢复交互；断开屏幕后位置可找回 |
| v0.6.0，候选 | 工作概览：CPU / 内存 / 网络、DSH、多会话 | 统计口径可解释；采集可关闭；来源和会话不会混淆 |
| v0.7.0，候选 | 生态与陪伴：完整包工具、番茄钟 / 休息提醒 | 社区能制作和校验包；提醒遵守安静规则 |
| 独立专题 | Spine 动画 | 原型证明性能、动作映射及可分发边界后再定版本 |

先完成一个版本再细化下一版；不提前为后续需求搭建通用插件市场、在线素材商店或复杂调度框架。

## 全局边界

- 桌宠观察 Agent 状态，不替用户批准命令、回复输入问题或执行任务。
- 不上传 Agent 对话、任务内容或系统指标；状态桥只保留必要的事件元数据。
- 无 Agent、未配置、断连、采集失败与“任务失败”是不同情况。
- 角色资源沿用仓库 [NOTICE](../../NOTICE.md) 的分层说明；代码开源不代表第三方素材可按代码协议再分发。
- Linux 尚未纳入；新增需求先入本表，再评审进入哪一版。
