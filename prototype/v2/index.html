接入方式

与 v1 完全一致，三种通道任选其一接入真实数据。
// 1) 直接调用
MiyoPet.setState({ processing: 3, pending: 2 });

// 2) 跨窗口 / iframe 消息
window.postMessage({ type:'miyo-state',
                     payload:{ processing:3, pending:2 } }, '*');

// 3) 本地服务轮询（同目录放 status.json 即自动生效）
//    { "processing": 3, "pending": 2 }

// 另有：多表情映射的控制接口
MiyoPet.getMapping();                 // 查看当前映射
MiyoPet.setMapping('processing', ['36','09']);   // 设为一组

互动动作

在左侧桌宠身上直接操作即可。连续点击会逐级递进——越点越开怀，点到第 7、8 次会不高兴。
反应只持续 1.5–3 秒，结束后自动回到当前工作状态的表情；反应期间也计为「有操作」。

表情映射（可多选）

每个状态可以关联多个表情，运行时会自动轮播（每 7 秒换一个）。 点 × 移除，右侧下拉可追加，点画廊的图也会追加到当前状态。
当前轮播到的表情会用实心绿标出。只有一个表情时不轮播。
